## 1. 설계 원칙 (기반)

PDFS는 "장비 상태를 모니터링하고 고장을 예측하는 시스템"으로, 현업 관제 대시보드(Grafana·Datadog 등)와 같은 부류다.

| 원칙 | 뜻 | PDFS 적용 |
|------|-----|----------|
| ① 정보 3단계 깊이 | 요약 → 목록 → 상세로 파고듦(drill-down) | 전체 숫자 → 위험 디스크 목록 → 디스크 진단 |
| ② 위험 우선 노출 | 정상은 조용히, 위험은 눈에 띄게 | 위험 디스크를 색·정렬로 상단에 |
| ③ 추세를 보여주기 | 시간에 따른 악화 흐름 표시 | SMART 시계열 차트로 "왜 위험한지" 설득 |

## 2. 화면 목록 (실제 구현 기준)

Streamlit 사이드바 라디오 메뉴 6개. 경로 없이 사이드바 선택으로 이동.

| 화면 | 사이드바 메뉴 | 목적 | 우선순위 | 기능 |
|------|-------------|------|:---:|------|
| 메인 대시보드 | `대시보드` | 전체 상태 한눈에 + 위험 강조 | 🔴 필수 | F-05, F-06, F-07 |
| 자동진단 | `자동진단` | smartctl로 실제 디스크 자동 진단 | 🔴 필수 | F-03 |
| 수동진단 | `수동진단` | SMART 값 직접 입력해 진단 | 🔴 필수 | F-02 |
| 디스크 상세 | `디스크 상세` | 개별 디스크 예측 결과·SMART 현재값 | 🔴 필수 | F-05 |
| 모델 성능 | `모델 성능` | 7개 모델 비교 표 조회 | 🟡 참고용 | F-01 결과 |
| 컬럼 설명 | `컬럼 설명` | SMART 항목 한국어 설명 | 🟡 참고용 | — |

> **로그인: 미적용.** 데모 중심 프로젝트이므로 인증은 넣지 않는다.

## 3. 화면별 상세

### 3-1. 대시보드 — 가장 중요

```
[헤더]
  PDFS 로고 · "실시간 연결됨 · 로컬 SMART 모니터링" · 실시간 점등 표시

[전체 현황 카드 4개]
  전체 N개 · ● 정상 N · ● 주의 N · ● 위험 N

[시스템 분석]
  위험도 분포 도넛 차트 | 최근 7일 위험·주의 추이 막대 차트

[데모 제어 패널]
  "목업 더미 데이터 표시" 사이드바 토글 → F-07

[⚠ 주의가 필요한 디스크]
  위험도 높은 순 2열 카드, 색 강조 (위험=빨강, 주의=노랑)

[전체 디스크 목록]
  Streamlit dataframe 테이블 (상태·시리얼·모델·용량·위험도·가동시간)

[위험 토스트 알림]
  위험 디스크 있으면 하단에 경고 박스 표시 → F-06
```

### 3-2. 자동진단

```
[디스크 목록 조회 버튼]
  smartctl --scan 실행 → 연결된 디스크 목록 표시

[디스크 선택 드롭다운]

[현재 상태 자동 진단 버튼]
  smartctl -a -j 실행 → 피처 추출 → ML 예측 → 결과 표시
  → 진단 결과가 대시보드에도 즉시 반영 (session_state)

[SMART 활성화 버튼]
  smartctl -s on 실행 (관리자 권한 필요)
```

> smartmontools 미설치 시 오류 안내 + winget 설치 명령 표시.

### 3-3. 수동진단

```
[입력 폼 2열]
  모델명 · 용량(TB) · 재할당섹터(5) · 가동시간(9) · 에러(187)
  명령타임아웃(188) · 온도(194) · 대기섹터(197) · 정정불가(198) · CRC오류(199)

[수동 진단 버튼]
  → ML 예측 + 규칙 판정 → 디스크 상세 화면과 동일한 레이아웃으로 결과 표시
```

### 3-4. 디스크 상세

```
[디스크 헤더]
  시리얼 번호 · 등급 뱃지 · 모델 · 용량 · 가동시간

[예측 결과 2열]
  왼쪽: 원형 위험도 게이지 (색상으로 등급 표시)
  오른쪽: 예측 분석 (위험 원인 태그 · 권장 조치)

[핵심 SMART 현재값]
  5개 카드 (재할당섹터·대기섹터·정정불가·에러·명령타임아웃)
  이상값은 빨강/노랑으로 강조
```

> 대시보드의 "디스크 상세" 메뉴에서 디스크를 선택해 이동. 또는 자동·수동 진단 직후 동일 레이아웃으로 결과 표시.

### 3-5. 모델 성능

```
scores/ 폴더 CSV 자동 감지 후 Streamlit dataframe으로 표시
  - storage_model_scores.csv (7개 모델 비교)
  - storage_recall_model_score.csv (있으면)
  - storage_threshold_search.csv (있으면)
```

### 3-6. 컬럼 설명

```
SMART 10개 컬럼 한국어 설명 테이블
(모델컬럼명 · 화면표시명 · 의미)
```

## 4. 화면 흐름 (네비게이션)

```
사이드바 (항상 노출)
  ├─ 대시보드   ← 메인 진입점
  ├─ 자동진단   ← 실제 디스크 진단 → 결과를 대시보드에 반영
  ├─ 수동진단   ← SMART 직접 입력 → 즉시 결과 확인
  ├─ 디스크 상세 ← 대시보드 디스크 선택 또는 진단 직후
  ├─ 모델 성능  ← 발표 참고용
  └─ 컬럼 설명  ← 팀원·발표 참고용
```

## 5. 사이드바 공통 컨트롤

```
[목업 더미 데이터 표시 토글]  ← F-07 데모 모드
  ON  → demo_disks() 7개 더미 디스크 + 실제 진단 결과 합산 표시
  OFF → 실제 진단 로그만 표시
```

## 6. 현업 근거 (면접 어필 포인트)

- **Overview → Detail drill-down**은 모든 관제 시스템의 표준 정보 위계.
- **위험 우선 노출**은 운영자가 문제를 빨리 찾게 하는 UX 원칙.
- **Streamlit**은 현업 데이터 과학팀이 사용하는 빠른 프로토타이핑·내부 도구 표준.
- 화면 수는 많지 않지만 진단 → 확인 → 조치 흐름을 모두 갖춘 완결 구성.

## 8. 화면 흐름 (사용 시나리오)

### 8-1. 평상시 사용 흐름 (운영자)

```
1. 대시보드 접속
   → 전체 현황 카드 확인 (정상 N · 주의 N · 위험 N)

2. 주의가 필요한 디스크 섹션에서 위험 디스크 발견

3. 사이드바 "디스크 상세" 선택 → 해당 디스크 선택
   → 위험도 게이지·SMART 현재값·권장 조치 확인

4. 현장 점검 후 데이터 백업·교체 조치
```

### 8-2. 데모 시연 흐름 (발표용)

```
1. 사이드바 "목업 더미 데이터 표시" 토글 ON
   → 위험 디스크(ZA12B9KL 92%) 포함 7개 더미 데이터 대시보드 표시
   → 위험 토스트 알림 등장

2. "디스크 상세" 에서 ZA12B9KL 선택
   → 게이지 92% · 위험 SMART 태그 · 권장 조치 시연

3. "수동진단" 으로 이동 → SMART 이상값 직접 입력
   → ML 예측 결과 실시간 확인 시연
```

### 8-3. 역할별 작업 매핑

| 흐름 단계 | 담당 |
|-----------|------|
| 모델 학습·평가 (F-01) | 데이터분석 (김응석) |
| SMART 자동 수집 (F-03) | 인프라 (안세웅) |
| Streamlit 앱 전체 화면 (F-05·F-06) | 프론트/개발 전체 |
| 더미 데이터·데모 구성 (F-07) | 인프라 |

## 9. 조치 라이프사이클 (F-08) — 미구현, 확장 과제

현재 앱에는 조치 상태 버튼(미확인→확인됨→조치완료)이 없다. MVP 완성 후 추가 예정.

```
🔴 미확인   →   👀 확인됨   →   ✅ 조치완료
(위험 감지)    (인지 완료)      (백업·교체 완료)
```

- 추가 방법: 디스크 상세 화면에 `st.button` 3단계 상태 추가 + `session_state`로 상태 유지.
- DB 저장이 필요하면 CSV 또는 SQLite 추가.
