## 0. 선정 기준

- "멋진 기술"이 아니라 **"PDFS에 꼭 필요한가"** 를 기준으로 선정.
- **실무에서 자주 쓰는 인프라 스택** 을 우선 채택 — Docker, Kubernetes, GitHub Actions.
- **실제 구현(`app_pdfs_mockup_v3.py`)을 기준으로 확정.** 계획과 달라진 부분은 이유를 함께 기록한다.

## 1. 확정 기술 스택

### v1 — 온프레미스 EXE (배포 완료)

| 영역 | 기술 | 담당 기능 |
|------|------|-----------|
| ML 학습 | Python · pandas · scikit-learn | F-01 모델 학습·평가 (storage·battery·symptom) |
| 모델 저장/로드 | joblib | `.pkl` 파일로 저장 → 앱에서 직접 로드 |
| 웹 앱 프레임워크 | **Streamlit** | 대시보드·자동진단·수동진단·상세·성능 화면 전체 |
| SMART 수집 | smartmontools (`smartctl`) | F-03 디스크 자동진단 (EXE에 동봉) |
| 데이터 저장 | CSV 로그 (`logs/`) | 진단 이력 누적 저장 |
| 상태 관리 | Streamlit `session_state` | 진단 결과·디스크 목록 화면 간 공유 |
| **패키징** | **PyInstaller** | **Streamlit 앱 + smartctl을 단일 EXE로 빌드** |

### v2 — 실무형 클라우드 인프라

| 영역 | 기술 | 담당 기능 | 상태 |
|------|------|-----------|------|
| 백엔드 API | **FastAPI** | SMART 수신·ML 예측·DB 저장 (포트 8010) | ✅ 완료 |
| DB | **PostgreSQL 15** | 진단 이력·디스크 상태 영구 저장 (포트 5432) | ✅ 완료 |
| 로컬 에이전트 | Python 스크립트 | smartctl 수집 → API 전송 (5분 간격) | ✅ 완료 |
| 대시보드 | **Streamlit 1.27.2** | API 데이터 시각화 대시보드 (포트 8501) | ✅ 완료 |
| 리버스 프록시 | **Nginx** | /api/* → FastAPI, /* → Streamlit 라우팅 (포트 80) | ✅ 완료 |
| 컨테이너화 | **Docker + Docker Compose** | 전체 서비스 컨테이너 통합 | ✅ 완료 |
| 컨테이너 오케스트레이션 | **Kubernetes (minikube)** | Pod 관리·무중단 배포·스케일 | 🔄 진행 중 |
| CI/CD | **GitHub Actions** | push → 이미지 빌드 → 자동 배포 | ⬜ 예정 |

> **Streamlit 1.27.2 고정 필수** — 1.58에서는 사이드바 접기 버튼(`collapsedControl`)이 제거됨. 1.27.2에서만 별도 fixed 버튼 동작.

> 상세 설계: [07_클라우드전환설계.md](07_클라우드전환설계.md)

## 2. 왜 이 인프라 스택인가

| 비교 항목 | 이전 계획 (Railway + Streamlit Cloud) | 현재 채택 (Docker + Nginx + K8s) |
|-----------|---------------------------------------|----------------------------------|
| 실무 유사도 | 설정 간단하지만 실무와 거리 있음 | 현업 표준 스택 그대로 |
| 확장성 | 플랫폼 종속 | 어떤 서버든 동일하게 배포 가능 |
| CI/CD | 플랫폼 내장 (제한적) | GitHub Actions로 완전 제어 |
| 포트폴리오 가치 | "무료 배포 경험" | "실무 인프라 구축 경험" |
| 학습 가치 | 낮음 | Docker / K8s / Nginx 전부 실습 |

## 3. 전체 아키텍처 흐름

```
[개발자 PC]
  git push → main 브랜치
        ↓
[GitHub Actions]
  1) Docker 이미지 빌드 (FastAPI · Streamlit · Nginx)
  2) Docker Hub push
  3) 서버 SSH 접속 → docker-compose pull & up
        ↓
[서버 — Docker Compose]
  ┌─────────────────────────────────────────┐
  │  Nginx (포트 80)                        │
  │    /api/* ─────→ FastAPI (8010)         │
  │    /*      ─────→ Streamlit (8501)      │
  │                                         │
  │  FastAPI  ←─── PostgreSQL (5432)        │
  └─────────────────────────────────────────┘
        ↓
[Kubernetes]
  Deployment · Service · Ingress · Secret
  → Pod 자동 재시작 / 무중단 배포

[로컬 PC — 경량 에이전트]
  smartctl 수집 → POST http://서버IP/api/diagnose
```
