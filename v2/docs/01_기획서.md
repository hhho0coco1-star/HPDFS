## 2. 배경 및 목적

하드디스크·SSD는 고장 나기 전에 **SMART(Self-Monitoring, Analysis and Reporting Technology)** 라는 자가 진단 수치를 남긴다. 배드섹터 수, 재할당 섹터 수, 가동 시간, 온도 등이다.

이 수치의 변화 패턴을 머신러닝으로 학습하면, **디스크가 완전히 죽기 전에 "곧 고장날 위험이 높다"를 미리 예측**할 수 있다. PDFS는 이 예측을 실시간으로 제공하는 것을 목표로 한다.

---

## 3. 예측 범위 (결정됨)

| 대상 | 데이터 상황 | 결정 |
|------|------------|------|
| **HDD/SSD** | Backblaze Drive Stats — 공개·풍부, 예제 다수 | ✅ **핵심 범위 · 모델 학습 완료** |
| **배터리** | 학습 완료 (`battery_best_model.pkl`, `battery_soh_best_regressor.pkl`) | ⏸ **앱 미구현 — 클라우드 전환 시 추가** |
| **증상** | 학습 완료 (`symptom_best_model.pkl`) | ⏸ **앱 미구현 — 클라우드 전환 시 추가** |
| RAM | 공개 데이터 부족, 시스템 로그 기반으로 난이도 높음 | ❌ 현 단계 제외 |

> **2026-06-09 확인:** ZIP 분석 결과 배터리(분류+SOH 회귀)·증상 모델이 이미 학습 완료 상태로 포함되어 있음. 앱에만 UI가 없는 상태. 클라우드 전환 시 API 엔드포인트로 함께 노출 예정.

## 4. 동작 형태 (결정됨)

**실시간 모니터링형(B) + 데모 시뮬레이션 모드(C)** 조합.

| 모드 | 설명 | 상태 |
|------|------|------|
| 평상시 (실시간) | PC에 설치한 에이전트가 SMART를 수집 → 서버 전송 → 대시보드에 실시간 상태·위험도 표시 | ✅ EXE 포터블로 구현 완료 |
| 발표용 (데모) | Backblaze의 "고장 직전 디스크" 데이터를 주입 → 위험 알림이 뜨는 과정을 시연 | ✅ 사이드바 토글로 구현 완료 |
| 클라우드 전환 | 로컬 에이전트 → 클라우드 API 전송 → 웹 대시보드 | ✅ Docker + Nginx + FastAPI + PostgreSQL 구현 완료 |

> **왜 데모 모드가 필요한가:** 실시간 모니터링만 하면, 시연하는 순간에 팀원 PC 디스크가 고장나 주지 않는다. 정상 디스크는 "위험 없음"만 표시되어 발표가 밋밋해진다. 핵심인 "고장 예측"을 보여주려면 고장 데이터를 주입하는 데모 모드가 필수다.

## 5. 시스템 구조

### v1 (현재 — 온프레미스 EXE)

```
[로컬 PC]
  HPDFS.exe (Streamlit + smartctl 동봉)
    ├── smartctl → SMART 수집
    ├── GradientBoosting 모델 → 예측
    ├── CSV 로그 → 이력 저장
    └── Streamlit → 대시보드 (localhost:8501)
```

### v2 (구현 완료 — Docker + 인프라 고도화 진행 중)

```
[로컬 PC — 경량 에이전트]
  smartctl 수집
     → HTTP POST ──────────→ [서버 — Docker Compose]
                                  Nginx (포트 80)
                                   ├── /api/* → FastAPI (8010)
                                   │             ↓
                                   │         PostgreSQL (5432)
                                   └── /*    → Streamlit (8501)

[인프라 고도화 진행 중]
  Kubernetes — Pod 자동 재시작·무중단 배포 (6단계)
  GitHub Actions CI/CD — push → 자동 배포 (7단계)
```

**폴더 구조 (2026-06-10 기준):**
```
HPDFS/
├── v1/data/HPDFS.zip    ← EXE 포터블 버전
└── v2/                  ← Docker 인프라 버전
    ├── agent/
    ├── backend/
    ├── frontend/
    ├── nginx/
    ├── docker-compose.yml
    └── docs/
```
