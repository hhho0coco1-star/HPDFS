## 1. MVP 범위

초보 팀일수록 범위를 작게 잡고 끝까지 완성하는 것이 성공 비결이다.
아래 **필수 기능 8개(F-01~F-08)** 만 먼저 완성한다. 이것만으로 "실시간 고장 예측 → 조치 → 완료"라는 완결된 프로젝트가 된다.

확장 기능(로그인, 여러 디스크 관리, 알림 이력, RAM 예측 등)은 MVP가 돌아간 뒤에 검토한다.

## 3. 기능별 상세

### F-01. 고장 예측 모델 학습 ✅

- Backblaze Drive Stats 1분기 데이터로 GradientBoosting 모델 학습 완료.
- 핵심 SMART 피처 10개 사용 (model · capacity + smart 5·9·187·188·194·197·198·199).
- 학습된 모델은 `models/storage_best_model.pkl`로 저장.
- ML 7개 모델 비교 후 GradientBoosting 확정 (상세: [03_데이터확인.md](03_데이터확인.md)).
- ML + 규칙 기반 하이브리드 판정으로 Recall 보완 (03 4-5 참고).

### F-02. 예측 실행 (모델 서빙) ✅

- 별도 FastAPI 서버 없이 Streamlit 앱 내 `predict()` 함수로 직접 실행.
- 입력: SMART 10개 피처 → 출력: ML 확률·등급·규칙 등급·최종 등급·원인·권장 조치.
- 자동진단(smartctl 결과)·수동진단(폼 입력) 두 경로 모두 동일 함수 사용.

### F-03. SMART 수집 (자동진단) ✅

- `smartctl -a -j` 실행 후 JSON 파싱 → ATA·NVMe 양쪽 처리.
- 연결된 디스크 자동 스캔 (`smartctl --scan`).
- smartmontools 미설치 시 오류 안내 + 설치 명령 표시.
- 관리자 권한 필요 시 `run_hpdfs_admin.bat` 사용.

### F-04. 수집 데이터 저장·조회 ✅

- 진단 결과를 `logs/storage_diagnosis_log.csv`에 누적 저장.
- 대시보드 로드 시 `load_log_as_disks()`로 최근 5개 결과 표시.
- 같은 디바이스 중복 진단 시 최신 결과만 표시.

### F-05. 실시간 대시보드 ✅

- 전체 현황 카드 (전체·정상·주의·위험 집계).
- 위험도 분포 도넛 차트 + 7일 추이 막대 차트.
- 주의 이상 디스크 카드 (위험도 높은 순 정렬, 2열).
- 전체 디스크 목록 테이블.
- 자동·수동 진단 후 `session_state`로 대시보드에 즉시 반영.

### F-06. 위험 알림 ✅

- 위험 디스크가 있으면 대시보드 하단에 토스트 알림 박스 표시.
- 가장 위험도 높은 디스크 시리얼·모델·위험도% 표시.

### F-07. 데모 모드 ✅

- 사이드바 토글 "목업 더미 데이터 표시" ON → `demo_disks()` 더미 7개 + 실제 진단 결과 합산 표시.
- 더미 데이터: 위험 1개(ZA12B9KL 92%)·주의 3개·정상 3개.
- 발표 시 토글 ON → 위험 알림 즉시 등장 시연 가능.

### F-08. 조치 상태 관리 🔲 미구현 — 확장 과제

- 목표: 위험·주의 디스크의 대응 상태를 **미확인 → 확인됨 → 조치 완료** 로 관리.
- 현재 앱에 없음. MVP 완성 후 추가 예정.
- 추가 방법: 디스크 상세 화면에 `st.button` 3단계 + `session_state`(임시) 또는 SQLite(영구).

## 4. ML 5단계 ↔ 기능 매핑

```
① 데이터 수집   → F-03 (smartctl), F-04 (CSV 저장)
② 데이터 전처리 → F-01 (학습 단계)
③ 모델 학습     → F-01
④ 평가          → F-01 (scores/ 결과)
⑤ 서빙          → F-02, F-05, F-06, F-07
```

---

## 5. 목표 눈높이

- 목표는 "완벽한 예측"이 아니라 **"고장 위험을 미리 경고"** 다.
- 현재 모델 성능(Recall 0.34)은 출발점이며, 규칙 기반 보완으로 실질적 탐지율을 높인다.
- F-08(조치 관리)은 유일한 미완성 기능으로, 팀이 시간 여유 시 추가하면 제품이 완결된다.
