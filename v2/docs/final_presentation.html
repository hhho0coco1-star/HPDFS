00 Project Overview
SMART 기반 저장장치 고장 예측 및 모니터링 시스템
HPDFS는 클라이언트 PC의 HDD/SSD SMART 데이터를 Agent가 수집하고, Backend가 ML 모델과 SMART 규칙 보정을 통해 고장 위험도를 계산한 뒤, PostgreSQL에 저장된 결과를 Dashboard에서 확인하는 시스템입니다.
문제 정의
재할당 섹터, 대기 섹터, 정정 불가 섹터, CRC 오류 등 SMART 지표는 일반 사용자가 해석하기 어렵습니다.
해결 방향
SMART 수집 → 모델 예측 → 규칙 보정 → 정상/주의/위험 등급화로 결과를 단순하고 빠르게 판단할 수 있게 했습니다.
v2 확장
단일 EXE 중심 구조에서 Agent, Backend, DB, Dashboard, Nginx, Docker/K8s 구조로 확장했습니다.

04 Wireframe
대시보드 중심의 화면 설계
사용자가 가장 먼저 봐야 하는 전체 상태, 위험 디스크, 진단 이력을 빠르게 확인하도록 화면을 구성했습니다.
대시보드: 전체 디스크 수, 정상/주의/위험 요약, 위험도 분포, 전체 목록
디스크 상세: 위험도, 최근 진단 이력, 주요 SMART 지표, 조치 상태 관리
정보 우선순위
전체 현황을 먼저 보여주고, 위험 디스크를 빠르게 선택할 수 있도록 구성했습니다.
관리자 흐름
대시보드 → 디스크 상세 → 조치 상태 변경 흐름을 기준으로 화면을 설계했습니다.
설명 보조
SMART 컬럼 설명과 수동진단을 제공해 시연과 이해도를 보완했습니다.
