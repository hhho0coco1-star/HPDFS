📋 프로젝트 개요

HPDFS API는 하드디스크 SMART 수치를 수집하여 ML 모델과 규칙 기반 로직으로 고장 위험도를 예측하는 시스템입니다.

데이터베이스는 PostgreSQL을 사용하며 SQLAlchemy ORM으로 관리됩니다. 총 2개의 테이블로 구성됩니다.

진단 요청마다 로그를 누적하는 diagnosis_log와, 디스크별 최신 상태만 유지하는 disks로 역할이 분리됩니다.

🤖 ML 기반 등급 (ml_level)
등급ML 확률 범위의미
정상 prob < 0.36 고장 가능성 낮음
주의 0.36 ≤ prob < 0.70 고장 가능성 중간, 모니터링 필요
위험 prob ≥ 0.70 고장 가능성 높음, 즉각 조치 필요
📏 규칙 기반 등급 (rule_level)
등급SMART 조건비고
위험 smart_197 > 0 또는 smart_198 > 0 대기/정정불가 섹터 존재
위험 smart_5 ≥ 100 재할당 섹터 매우 많음
위험 smart_187 > 0 수정 불가 오류 발생
주의 smart_5 > 0 또는 smart_188/199 > 0 경미한 이상 감지
주의 smart_194 ≥ 50 온도 과열 (50℃ 이상)
정상 위 조건 해당 없음 이상 없음
⚡ 최종 등급(final_level)은 ml_level과 rule_level 중 더 높은 등급을 채택합니다.   정상 < 주의 < 위험  —  ML 확률이 낮더라도 위험 SMART 지표가 감지되면 위험으로 판정합니다.
