1
운영자가 전체 디스크 상태를 확인한다
📊 대시보드
Who
운영자
What
전체 디스크의 정상/주의/위험 상태를 확인
When
시스템 점검 시
Why
위험 디스크를 빠르게 식별하고 우선순위를 정하기 위해
How
접속 → 데이터 조회 → 현황 분석 → 위험 알림 확인
결과
위험 디스크의 우선 조치 대상을 판단할 수 있다.
2
발표자가 데모 데이터를 켜서 시연한다
🌙 데모 모드 토글
Who
발표자
What
데모 데이터를 주입/삭제하여 시연 환경을 준비
When
발표 준비 및 시연 중
Why
실제 디스크 데이터 없이 시스템 기능을 시연하기 위해
How
데모 모드 ON → 더미 데이터 주입 / OFF → 데이터 삭제
결과
대시보드·알림·상세 화면을 시연 환경에서 확인할 수 있다.
3
에이전트가 자동으로 디스크를 진단한다
🤖 자동진단 (에이전트)
Who
운영자
What
로컬 PC의 SMART 데이터를 수집하고 서버에 전송
When
에이전트 실행 후 5분 간격
Why
디스크 상태를 지속적으로 모니터링하기 위해
How
에이전트 실행 → SMART 수집 → API 전송 → 진단/저장 → 반복
결과
대시보드와 디스크 상세에서 자동 진단 결과를 조회할 수 있다.
4
사용자가 SMART 값을 직접 입력해 수동진단한다
✏️ 수동진단
Who
운영자 / 발표자 / 개발자
What
SMART 값을 입력하여 즉시 진단 결과 확인
When
필요할 때 (즉시)
Why
특정 SMART 값 조합의 위험도를 즉시 확인하기 위해
How
값 입력 → 진단 실행 → 결과 확인 (게이지, 등급, 원인, 조치)
결과
입력한 SMART 값에 대한 고장 위험도를 즉시 확인할 수 있다.
5
운영자가 위험 디스크의 조치 상태를 변경한다
💽 디스크 상세
Who
운영자
What
위험/주의 디스크의 조치 상태를 관리
When
위험 디스크 확인 후
Why
대응 진행 상태를 체계적으로 관리하기 위해
How
디스크 선택 → 상태 변경 → 저장 (PATCH)
결과
조치 진행 상황이 시스템에 반영되고 이력이 관리된다.

사용자가 SMART 컬럼 의미를 확인한다
📖 컬럼 설명
Who
운영자 / 발표자 / 개발자
What
SMART 컬럼의 의미와 해석 방법을 확인
When
필요할 때
Why
SMART 지표를 정확히 이해하고 해석하기 위해
How
컬럼 설명 페이지 → 항목별 의미 및 설명 확인
결과
SMART 지표를 이해하고 진단 결과를 올바르게 해석할 수 있다.
