❌ 문제 상황
ML 모델만으로는 위험 디스크를 3개 중 1개밖에 못 잡는다
GradientBoosting 모델의 Recall이 0.34에 불과해 위험 디스크 10개 중 6~7개를 정상으로 잘못 판정. 고장 예측 시스템의 핵심 지표가 기준치 이하였습니다.
위험 클래스 Recall : 0.34  ← 고장 탐지 실패율 66%
🔍 원인 분석
데이터 불균형 — 정상:고장 = 200:1
Backblaze 데이터셋 특성상 고장 디스크는 전체의 0.5% 미만. "전부 정상"으로 예측해도 Accuracy 99%가 나오기 때문에 모델이 고장 패턴을 학습할 유인이 없었습니다.
✅ 해결 방법 — ML + 규칙 기반 하이브리드 예측 도입 (두 결과 중 더 높은 위험 등급 채택)

AFTER 하이브리드 판정
def rule_level(row):
    if row["smart_197_raw"] > 0 or row["smart_198_raw"] > 0:
        return "위험"   # 대기섹터·정정불가
    if row["smart_5_raw"] >= 100 or row["smart_187_raw"] > 0:
        return "위험"
    if row["smart_194_raw"] >= 50:
        return "주의"
    return "정상"

def predict(df, model):
    ml_lv   = prob_to_level(model.predict_proba(df)[0][1])
    rule_lv = rule_level(df.iloc[0])
    return combine_level(ml_lv, rule_lv)  # max 취합
📈 결과 및 교훈
SMART 치명 지표(대기섹터·정정불가)가 1 이상이면 ML 확률 무관하게 위험 판정. 고장 예측은 False Negative(놓침)가 False Positive(오경보)보다 치명적이므로 보수적 판정이 올바른 설계.
